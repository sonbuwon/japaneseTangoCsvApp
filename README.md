# CsvTango

CSV 파일로 일본어 단어장을 만들어 암기하고 시험을 볼 수 있는 안드로이드 앱입니다.

## 주요 기능

- **CSV 업로드** — CSV 파일을 불러와 주제(단어장)로 저장 (UTF-8 / EUC-KR / Shift_JIS 자동 인식)
- **암기** — 카드 넘기며 단어 학습, 폴더로 주제 정리, 일본어 음성 읽기(TTS)
- **시험** — 범위를 골라 히라가나·뜻 맞히기 (괄호 안 내용은 생략해도 정답 처리)

## CSV 형식

첫 줄 헤더(`일본어,히라가나,한국어` 등)는 있어도 되고 없어도 됩니다.

기본 (3열):

```csv
일본어,히라가나,한국어
食べる,たべる,먹다
```

예문 포함 (6열):

```csv
일본어,히라가나,한국어,예문,예문 히라가나,예문 뜻
食べる,たべる,먹다,ご飯を食べる,ごはんをたべる,밥을 먹다
```
